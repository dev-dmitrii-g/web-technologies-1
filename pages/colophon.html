Colophon

Technical Project Overview

This website was created as part of our Web Technologies Assignment 1 coursework. The project builds an unstyled, pure HTML5 website for DAMDYM, a real neighborhood tobacco shop located near where I live at Turkestan 32 street.

The site focuses on semantic HTML structure, proper accessibility attributes, valid document hierarchy, form inputs, and relative page linking without external CSS stylesheets or JavaScript frameworks.
